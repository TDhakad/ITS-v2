# Confidential Docs

Use this article when a user asks how to access, store, share, or reference a
confidential document.

Confidential documents are restricted company materials. They may include
security reviews, legal documents, customer commitments, financial records, or
private operational details. This mock article does not contain real
confidential content.

## Handling Rules

Store confidential documents only in approved company systems. Do not upload
them to personal storage, public links, unmanaged chat tools, or external AI
services.

Do not paste confidential document contents into helpdesk tickets unless the
ticket queue is approved for restricted information. Use a link to the approved
document location and summarize the access issue without exposing sensitive
content.

## Access Requests

1. Ask the user for the document title, owning team, and business reason.
2. Confirm whether the user is requesting read access, edit access, or ownership
   transfer.
3. Route the request to the document owner or data steward for approval.
4. Apply an expiration date when access is temporary.

## Redaction Guidance

When sharing excerpts for troubleshooting, remove customer identifiers, employee
personal data, contract terms, secrets, and private infrastructure details.

## Escalation

Escalate to security if a confidential document was shared publicly, sent to the
wrong recipient, copied into an unapproved system, or may contain exposed
credentials.
