# UI Rendering and Browser Cache Issues

For UI bugs such as missing buttons, stale styles, or broken layouts, collect browser name, app name, environment, screenshot availability, and the last known working time.

Safe user-facing fixes:

1. Hard refresh the page.
2. Clear cached data for the affected application.
3. Disable browser extensions temporarily.
4. Try a supported browser.

Escalate if the issue affects multiple users, blocks a critical workflow, or reproduces after cache and browser checks.
