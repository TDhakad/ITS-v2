# VPN Connectivity Troubleshooting

For standard users, safe VPN troubleshooting is limited to client restart, network checks, and credential verification. Ask whether the user is on a trusted network, whether other sites load, and what VPN error code appears.

Self-service steps:

1. Confirm the local internet connection works.
2. Restart the VPN client.
3. Re-enter credentials without saved passwords.
4. Check whether the outage banner reports a known incident.

Escalate requests involving firewall rules, split tunnel policy, certificate rotation, privileged routes, or production network access changes.
