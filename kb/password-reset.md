# Password Reset and MFA Recovery

Use the identity portal password reset flow when a user can still access their recovery email or enrolled authenticator. Ask the user to confirm the affected account, whether MFA is still available, and the exact error shown by the identity portal.

Escalate to the helpdesk queue when the user has lost all MFA factors, requests access for another person, or asks to bypass approval.

Recommended first steps:

1. Open the identity portal.
2. Choose the password reset option.
3. Complete the MFA challenge.
4. Restart the browser and sign in again.
